## What each switch removes

- **V_no_log** passes no log profile to GLASS: the generation prompt has no event-log evidence section, and the context evidence is missing too, because GLASS takes it from the log profile's context profile (statistically screened relationships between context factors and metrics; `knowledge/retrieval.py`) (GLASS notes "Log evidence: not available" and "Context evidence: not available").
- **V_no_context** removes only the chat-derived constraints: the clarification chat is empty, so the prompt has no constraints section from the chat. The log-derived context relationships stay in the prompt (GLASS notes e.g. "Context: 6 significant relationships"); they are removed only in V_no_log.
- **V_no_refine** sets `max_iterations` to 1: the first proposal is evaluated once; if it does not improve, the loop keeps the baseline (`no_improving_scenario`).
- **V_old_refine** runs the loop with `legacy_refinement=True` (v2 stop and selection rules).
