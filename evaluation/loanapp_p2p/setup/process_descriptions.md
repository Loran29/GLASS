## LoanApp

Used by: LoanApp_G1, LoanApp_G2, LoanApp_G3, LoanApp_G1G2, LoanApp_G1G3, LoanApp_G2G3, LoanApp_G1G2G3

The loan assessment process takes place between an applicant and a loan provider, with the purpose of approving home loan applications. This process is executed by five roles within the loan provider: a clerk takes care of the application form and the administrative steps; an appraiser is responsible for appraising the property; an AML investigator performs the anti-money-laundering check; a loan officer assesses the loan risk and prepares the loan offer; and a senior officer approves the loan offer. The loan assessment process starts upon the receipt of a loan application from an applicant. Once a loan application is received by the loan provider, a clerk checks it for completeness. If the application is incomplete, it is returned to the applicant, so that they can fill out the missing information and send it back to the loan provider. This is repeated until the application is found complete. Once the application has been deemed complete, it must pass three checks, which are carried out in parallel: a clerk checks the applicant's credit history, an appraiser appraises the property for which the loan has been asked, and an AML investigator performs the anti-money-laundering check on the applicant. Once all three checks have been performed, a loan officer assesses the loan risk. If the risk is too high, the application is rejected. Otherwise, the loan officer designs a loan offer, which a senior officer must approve. If the senior officer approves the offer, the application is approved; if not, it is cancelled. In either case, the process completes. All staff of the loan provider work Monday to Friday, 09:00 to 17:00.

## Procure2Pay

Used by: Procure2Pay_G1, Procure2Pay_G2, Procure2Pay_G3, Procure2Pay_G1G2, Procure2Pay_G1G3, Procure2Pay_G2G3, Procure2Pay_G1G2G3

The procure-to-pay process covers purchases from requisition to payment. In the first stage, purchasing agents create, analyze and, if needed, amend the purchase requisition and create requests for quotation on behalf of the requester manager; requesters create and amend their own requests for quotation, and requester managers amend requests for quotation on their side. The order of these steps is flexible and steps can be repeated. In the second stage, purchasing agents analyze the returned quotations and the supplier provides the quotation comparison map; requests for quotation may be amended again. In the final stage, the supplier releases the invoice, the financial manager authorizes the invoice payment, settles any dispute with the supplier, and pays the invoice; some of these steps may be skipped or revisited. Every case ends with the invoice being paid. All staff work Monday to Friday, 09:00 to 17:00.
